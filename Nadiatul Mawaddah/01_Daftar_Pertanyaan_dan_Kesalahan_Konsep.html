Pertanyaan 8 — Pemahaman BERTopic (hal. 15-16)

“Bagaimana BERTopic menangani dokumen outlier/noise?”

Jawaban Ideal: Berdasarkan dokumentasi BERTopic:

  • Outlier ditandai sebagai Topic -1
  • Penyebab: dokumen tidak cukup dekat dengan cluster manapun

Pertanyaan 13 — Proses Pelabelan Manual (hal. 29)

“Siapa yang melakukan pelabelan? Bagaimana mengukur konsistensi?”

Jawaban Ideal: Berdasarkan best practices dari PMC:

Yang seharusnya dilakukan: 1. Minimal 2-3 labeler untuk subset data (10-20%) 2. Hitung Cohen’s Kappa (κ): κ = (Po - Pe) / (1 - Pe) - Po = observed agreement - Pe = expected agreement by chance

  1. Interpretasi Kappa (Landis & Koch, 1977): | Nilai κ | Interpretasi | |———|————–| | 0.81-1.00 | Almost perfect | | 0.61-0.80 | Substantial (acceptable) | | 0.41-0.60 | Moderate | | < 0.41 | Fair to poor |

  2. Target minimum: κ ≥ 0.60 (substantial agreement)

Jika hanya 1 labeler: - Sebutkan sebagai keterbatasan - Lakukan re-labeling untuk subset (10%) setelah beberapa waktu untuk cek konsistensi internal

Parameter Kunci yang Harus Ditentukan:

from bertopic import BERTopic
from umap import UMAP
from hdbscan import HDBSCAN

# UMAP parameters
umap_model = UMAP(
    n_neighbors=15,      # 5-50, lebih kecil = lebih lokal
    n_components=5,      # dimensi reduksi
    min_dist=0.0,        # 0.0 baik untuk clustering

    min_samples=10,          # mengurangi noise/outlier

    cluster_selection_method='eom',  # atau 'leaf' untuk lebih banyak topik
    prediction_data=True
)

    hdbscan_model=hdbscan_model,
    language="indonesian",
    calculate_probabilities=True,
    verbose=True
)

Tuning Strategy:

Masalah Parameter Solusi
Terlalu banyak topik min_cluster_size Naikkan (20-50)
Terlalu sedikit topik min_cluster_size Turunkan (5-10)
Banyak outlier (Topic -1) min_samples Turunkan
Topik tidak koheren n_neighbors Turunkan (5-10)

Jumlah topik ideal: Tergantung dataset, umumnya 10-30 topik untuk 2.000-3.000 dokumen.

Pertanyaan 21 — Validasi Interpretasi Topik (hal. 39-40)

“Siapa yang melakukan interpretasi topik? Ada validasi dari expert?”

Jawaban Ideal:

Evaluasi topic model harus menggunakan kombinasi metode kuantitatif (automated metrics) dan metode kualitatif (human judgment). Berikut penjelasan lengkap:

A. METODE KUANTITATIF (Automated Metrics)
1. Topic Coherence Metrics

Topic coherence mengukur seberapa koheren kata-kata dalam satu topik berdasarkan co-occurrence dalam corpus.

Metrik Formula/Pendekatan Interpretasi Score Kelebihan Kekurangan
NPMI (Normalized PMI) $$NPMI(w_i, w_j) = \frac{PMI(w_i, w_j)}{-\log P(w_i, w_j)}$$ -1 hingga +1 (≥ 0.1 acceptable) Menormalisasi frekuensi kata Perlu external corpus
C_V Kombinasi NPMI + cosine similarity 0-1 (≥ 0.5 good) Paling komprehensif Sensitif terhadap noise
UCI (C_UCI) PMI dengan sliding window external corpus Negatif hingga positif Menggunakan Wikipedia sebagai referensi Tidak cocok untuk bahasa non-English
UMass (C_UMass) $$C_{UMass}(w_i, w_j) = \log\frac{D(w_i, w_j) + 1}{D(w_j)}$$ Negatif (mendekati 0 = lebih baik) Tidak perlu external corpus Bisa bias pada corpus kecil

Rekomendasi untuk BERTopic Indonesia: Gunakan NPMI karena paling robust dan didukung langsung oleh BERTopic.

Referensi: Röder et al. (2015), Baeldung

# Implementasi dengan BERTopic
from bertopic import BERTopic
from gensim.models.coherencemodel import CoherenceModel
from gensim.corpora import Dictionary

# Setelah training BERTopic
topics = topic_model.get_topics()
topic_words = [[word for word, _ in topic_model.get_topic(topic_id)]
               for topic_id in range(len(topics)-1)]  # exclude -1 (outlier)

# Buat dictionary dan corpus untuk Gensim
tokenized_docs = [doc.split() for doc in documents]
dictionary = Dictionary(tokenized_docs)
corpus = [dictionary.doc2bow(doc) for doc in tokenized_docs]

# Hitung NPMI Coherence
coherence_model = CoherenceModel(
    topics=topic_words,
    texts=tokenized_docs,
    dictionary=dictionary,
    coherence='c_npmi'  # atau 'c_v', 'u_mass'

coherence_score = coherence_model.get_coherence()
print(f"NPMI Coherence: {coherence_score:.4f}")

Threshold Coherence Score:

Metrik Poor Acceptable Good Excellent
NPMI < 0.0 0.0 - 0.1 0.1 - 0.2 > 0.2
C_V < 0.3 0.3 - 0.5 0.5 - 0.7 > 0.7
UMass < -4.0 -4.0 to -2.0 -2.0 to -1.0 > -1.0
2. Topic Diversity Metrics

Topic diversity mengukur seberapa berbeda/unik topik-topik yang dihasilkan.

Metrik Formula Range Interpretasi
TD (Topic Diversity) $$TD = \frac{\|unique\ words\ in\ top-N\ of\ all\ topics\|}{K \times N}$$ 0-1 ≥ 0.8 = topik beragam
Inverted RBO Rank-Biased Overlap antar topik 0-1 ≥ 0.7 = rendah redundansi
Pairwise Jaccard Jaccard distance antar pasangan topik 0-1 ≥ 0.8 = topik berbeda

Referensi: Dieng et al. (2019), GitHub Topic Diversity

# Hitung Topic Diversity sederhana
def compute_topic_diversity(topic_model, top_n=25):
    topics = topic_model.get_topics()
    all_words = []
    for topic_id in topics:
        if topic_id != -1:  # exclude outlier topic
            words = [word for word, _ in topic_model.get_topic(topic_id)[:top_n]]
            all_words.extend(words)

    unique_words = set(all_words)
    num_topics = len([t for t in topics if t != -1])
    diversity = len(unique_words) / (num_topics * top_n)
    return diversity

td_score = compute_topic_diversity(topic_model)
print(f"Topic Diversity: {td_score:.4f}")
# Target: TD ≥ 0.8
3. Kombinasi Metrik: Quality Score

Untuk evaluasi komprehensif, gabungkan coherence dan diversity:

# Quality Score (Dieng et al., 2019)
quality_score = coherence_score * diversity_score
print(f"Topic Quality Score: {quality_score:.4f}")
B. METODE KUALITATIF (Human Evaluation)

Metode kualitatif dianggap gold standard untuk evaluasi topic model karena melibatkan penilaian manusia. Referensi utama: Chang et al. (2009) “Reading Tea Leaves”

1. Word Intrusion Task

Tujuan: Mengukur koherensi semantik topik

Prosedur: 1. Pilih 5 kata teratas dari satu topik 2. Tambahkan 1 kata “intruder” dari topik lain 3. Minta evaluator mengidentifikasi kata yang tidak sesuai 4. Hitung Model Precision = % evaluator yang benar mengidentifikasi intruder

Hasil Interpretasi
Model Precision > 80% Topik sangat koheren
Model Precision 60-80% Topik cukup koheren
Model Precision < 60% Topik perlu diperbaiki

Contoh:

Topik "Gaming Performance":
[lag, fps, freeze, server, crash, ████████]

Mana kata yang tidak sesuai?
A. lag    B. fps    C. freeze    D. ekonomi    E. crash    F. server

Jawaban benar: D (ekonomi) - intruder dari topik lain
2. Topic Intrusion Task

Tujuan: Mengukur seberapa baik topik merepresentasikan dokumen

Prosedur: 1. Tampilkan judul + snippet dokumen 2. Tampilkan 3 topik dengan probabilitas tertinggi untuk dokumen tersebut 3. Tambahkan 1 topik “intruder” (probabilitas rendah) 4. Minta evaluator memilih topik yang tidak sesuai dengan dokumen

3. Expert Topic Labeling

Prosedur untuk penelitian skripsi:

  1. Minimal 2 evaluator melakukan labeling independen
  2. Setiap evaluator memberi nama topik berdasarkan 10 kata teratas
  3. Hitung Inter-Rater Agreement menggunakan:
    • Fleiss’ Kappa (untuk > 2 evaluator)
    • Cohen’s Kappa (untuk 2 evaluator)
from sklearn.metrics import cohen_kappa_score

# Contoh: 2 evaluator memberi label untuk 15 topik
evaluator1 = [1, 2, 1, 3, 2, 1, 3, 2, 1, 2, 3, 1, 2, 1, 3]  # label kategori
evaluator2 = [1, 2, 1, 3, 1, 1, 3, 2, 1, 2, 3, 1, 2, 2, 3]

kappa = cohen_kappa_score(evaluator1, evaluator2)
print(f"Cohen's Kappa: {kappa:.3f}")
Nilai Kappa Interpretasi
0.81 - 1.00 Almost perfect agreement
0.61 - 0.80 Substantial (target minimum)
0.41 - 0.60 Moderate
< 0.41 Perlu revisi kriteria labeling

    results['num_topics'] = len(topic_model.get_topics()) - 1  # exclude -1

    # Print summary
    print("=" * 50)
    print("TOPIC MODEL EVALUATION SUMMARY")
    print("=" * 50)
    print(f"NPMI Coherence : {results['npmi']:.4f} (target ≥ 0.1)")
    print(f"Topic Diversity: {results['diversity']:.4f} (target ≥ 0.8)")
    print(f"Outlier Ratio  : {results['outlier_ratio']:.2%} (target < 15%)")
    print(f"Number of Topics: {results['num_topics']}")
    print("=" * 50)

    return results
